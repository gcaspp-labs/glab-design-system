# Logos

Marca GCASPP LAB: o polvo no disco. Todos são SVG de uma cor por elemento, com o polvo e as ondas vazados (transparentes).

- `glab-simbolo.svg` — símbolo em `accent` claro (#01466F). Fundos claros, favicon, avatar.
- `glab-simbolo-escuro.svg` — símbolo em `accent` escuro (#4BAECE). Barra lateral e tema escuro.
- `glab-simbolo-ink.svg` — símbolo em `ink` (#222222). Impressão monocromática.
- `glab-simbolo-branco.svg` — símbolo em branco. Sobre fotos ou cores sólidas escuras.
- `gcaspp-lab-horizontal.svg` — símbolo + "GCASPP" (IBM Plex Sans 600, `ink`) + "LAB" (IBM Plex Mono 500, `accent`). Cabeçalhos de documentos, login, site.
- `gcaspp-lab-horizontal-escuro.svg` — a mesma assinatura para fundos escuros ("GCASPP" #EBEBEB, "LAB" #86CBE2).
- `g-lab.svg` / `g-lab-escuro.svg` — símbolo + "g-lab" (IBM Plex Mono 500). Espaços curtos e uso interno.

Os textos estão convertidos em curvas: não dependem de fonte instalada.
