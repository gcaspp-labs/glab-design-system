# FormField

Campos de formulário: `field` (rótulo + controle + dica), `field-row` em duas colunas, `fieldset` tracejado para grupos repetíveis com `repeat-row`, e `check-row`.

- Rótulo em `label` (`ink-soft`), sempre visível; dica em `hint-text` abaixo.
- Foco do campo troca a borda para `accent`; foco de teclado mostra o anel `focus`.
- Grupos repetíveis: cada linha termina em `icon-btn` de remover e o grupo em `add-row-btn`.
- O consumidor fornece rótulos, valores e validação.
