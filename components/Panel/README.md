# Panel

Contêiner padrão de conteúdo: `surface`, borda `line`, raio `radius-12`, sem sombra.

- Cabeçalho com título `title-panel`, dica opcional em `caption` e ações `btn-sm` à direita.
- `panel-body` tem 18/20px de padding; use `pad-0` quando o corpo é uma tabela.
- O consumidor fornece título, conteúdo e ações.
