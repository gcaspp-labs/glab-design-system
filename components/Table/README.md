# Table

Tabela de registros (`table.table`) dentro de um Panel com `pad-0`.

- Cabeçalho em `table-head` (maiúsculas, `ink-faint`); números e moedas em `num` (mono, à direita).
- Primeira coluna: `cell-title` + `cell-sub`. Linhas `clickable` abrem o detalhe.
- O consumidor fornece colunas e linhas; envolva em `table-wrap` para rolagem horizontal no celular.
