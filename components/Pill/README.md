# Pill

Pill de status de contrato, fatura ou cliente: ponto colorido + palavra.

- `pill-success` Vigente/Pago/Ativo; `pill-warning` prazos próximos ("Vence em 12 dias"); `pill-danger` vencido ("Vencido há 3d"); `pill-neutral` encerrado/inativo (sem ponto).
- A palavra é obrigatória: a cor nunca carrega o status sozinha. No tema claro `success` e `warning` sobre o fundo suave ficam abaixo de 4,5:1 (herdado do Contratos GCASPP), por isso o texto curto e em peso 600.
- O consumidor fornece apenas o texto; uma linha, sem quebra.
