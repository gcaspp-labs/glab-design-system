# Sidebar

Barra lateral escura (`sidebar-bg` nos dois temas) com a marca no topo, menu e rodapé.

- Marca: `gcaspp-simbolo-escuro.svg` com 32px de altura (largura automática) + "GCASPP" (14,5px, 600) e o nome do produto abaixo ("Gestão de Contratos").
- Itens com ícone de 17px; ativo em `accent-strong` sobre `accent-soft`; grupos com `nav-group-label`; submenus em `nav-sub`.
- Largura `sidebar-width`; abaixo de 760px vira gaveta aberta pelo `menu-btn` da Topbar.
- O consumidor fornece itens, ativo e o nome do produto.
