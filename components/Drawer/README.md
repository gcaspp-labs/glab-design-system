# Drawer

Painel lateral direito para criar e editar registros sem sair da lista; largura `drawer-width` (até 92vw), sombra `shadow`, véu `overlay`.

- Cabeçalho `title-drawer` + fechar; corpo com FormField; rodapé com Cancelar (ghost) e a ação primária.
- Fecha com Esc, clique no véu e no X.
- O consumidor fornece título, formulário e ações.
