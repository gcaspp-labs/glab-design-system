# Icons

Conjunto de ícones de traço do Contratos GCASPP: grade 24×24, traço 1,7, pontas e junções arredondadas, `fill="none"`, `stroke="currentColor"`.

- Tamanhos: 17px no menu, 15px em botões, 14px em controles pequenos, 30px em estados vazios.
- Herdam a cor do texto (`currentColor`); nunca preencha.
- Inclua inline com: `<svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="1.7" stroke-linecap="round" stroke-linejoin="round">…</svg>`.
- Nomes disponíveis: `home`, `layers`, `users`, `building`, `box`, `file`, `receipt`, `settings`, `chevDown`, `plus`, `close`, `paperclip`, `search`, `back`, `trash`, `check`, `star`, `calendar`, `warn`, `menu`. Os desenhos estão no preview; para um ícone novo, siga a mesma grade e traço.
